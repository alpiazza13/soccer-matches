#Matches Queue
Full-stack web app built with FastAPI, React (Next.js), Postgres, and AWS - live at http://www.matchesqueue.com. I use it as a to-do list to keep track of which soccer matches I've already watched highlights for.
Fetches data from the free tier of https://www.football-data.org/, which includes the top 5 European leagues, Champions League, and major international tournaments.
